# CLAUDE.md

## This repository is PUBLIC. Every push is publishing.

Anything committed and pushed here, on any branch, can be read by anyone on the
internet. Deleting it later does not reliably remove it. Read this before committing.

Never commit, on any branch, without Ryan's explicit approval in the current session:

- Personal information (addresses, phone numbers, machine names, account handles
  beyond what is already on ryanseslow.com).
- Business information: pricing, rate floors, client names, client details, lead
  lists, strategy, income, or "operator profile" style files.
- Credentials of any kind, including session cookies and .env files.
- Captured or scraped data.

Before the first push in any session, state to Ryan that the repo is public and list
the files being pushed. If a tool needs a personal profile or config to work, ship
only a blank template with placeholder values and keep the real file git-ignored.

Work-in-progress experiments belong in a private repository, not here. Only finished
tools that are meant to be public go in this repo.
